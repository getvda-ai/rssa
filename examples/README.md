# Examples

- `minimal-card.json` and `minimal-feed.atom`: the **core only**, with no signing. This is the smallest compliant agent.
- A **complete signed group** (Atom, RSS 2.0 and JSON Feed members, a signed card, a signed `policy.json`, and `roster.opml`) is in [`../demo/site/`](../demo/site/). It is generated by `scripts/make-demo.ts`, and `npm run check` validates it.
- **Inputs that must fail** are in [`../demo/broken/`](../demo/broken/), with the expected error code for each in `EXPECTED.json`.
